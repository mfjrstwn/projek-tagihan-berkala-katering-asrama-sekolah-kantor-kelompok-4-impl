# Foto kartu paket

Letakkan foto di folder ini dengan nama berkas persis seperti berikut (format JPG):

| Berkas | Dipakai untuk nama paket yang memuat |
|---|---|
| sarapan.jpg | "sarapan" atau "pagi" |
| makan-siang.jpg | "siang" |
| makan-malam.jpg | "malam" |
| siang-malam.jpg | "siang" dan "malam" sekaligus |
| instansi.jpg | "instansi", "kantor", "acara", "prasmanan", "porsi" |
| umum.jpg | nama lain yang tidak dikenali |

Saran: rasio 4:3, sekitar 800 x 600 px, di bawah 150 KB. Foto yang belum ada tidak merusak
tampilan; kartu menampilkan huruf awal nama paket di atas latar teal lembut.
